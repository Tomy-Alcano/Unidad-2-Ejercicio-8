# Unidad-2-Ejercicio-8
Programacion 3 Unidad 2 Ejercicio 8
Ejercicio 8 — Panel interactivo con MouseListener
En este ejercicio vas a trabajar con MouseListener para que un panel responda visualmente al movimiento y los clics del mouse, practicando eventos que van más allá del simple clic en un botón.

Construí una ventana que contenga:

Un JPanel central de al menos 300 x 200 píxeles que funcione como área interactiva
Una etiqueta en la parte inferior que muestre el estado actual del panel
El panel debe comportarse de la siguiente manera:

Cuando el cursor entre al área del panel, el fondo del panel debe cambiar a un color a tu elección y la etiqueta debe mostrar "El cursor está dentro del panel"
Cuando el cursor salga del área del panel, el fondo debe volver al color original y la etiqueta debe mostrar "El cursor salió del panel"
Cuando el usuario haga clic dentro del panel, la etiqueta debe mostrar la posición exacta del clic en formato: "Clic en: X=150, Y=80" (con los valores reales de la posición)
💡 Tip: el objeto MouseEvent que recibís en cada método del listener tiene los métodos getX() y getY() que devuelven la posición del cursor en el momento del evento.
